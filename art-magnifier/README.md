# 명화 돋보기 탐험

초등 미술 감상 수업용 웹앱입니다. 학생들이 명화를 돋보기로 확대해 자세히 살펴보고, 찾은 특징을 작품 위에 표시하고 기록합니다.

- 사용 주소: https://yeoninglove-rgb.github.io/art-magnifier/
- 마우스: 작품 위에서 움직이며 살펴보고, 클릭하면 돋보기가 멈춥니다.
- 태블릿: 손가락으로 끌어서 살펴봅니다. 돋보기가 손가락 위에 떠서 가려지지 않습니다.
- [작품 추가]로 다른 작품 사진을 넣을 수 있습니다. 추가한 사진과 발견 기록은 각자의 브라우저에만 저장됩니다.

기본 작품은 저작권이 끝난 명화로, 위키미디어 공용(commons.wikimedia.org)에서 불러옵니다.
